Del enlace a Giramesa

Elegí tu plataforma. Cada permiso tiene un motivo y puede retirarse después.

Instalar en Android

  1. Descargá el APK. Usá únicamente el botón de esta página y comprobá el nombre y, si está publicado, el SHA-256.
  2. Abrí la descarga. Android puede pedir permiso al navegador o gestor de archivos para instalar aplicaciones desconocidas.
  3. Concedé el permiso de forma puntual. Confirmá la instalación y desactivá después ese permiso desde Ajustes.
  4. Abrí Giramesa. Si Android muestra una advertencia inesperada o el archivo no coincide, cancelá y comunicalo.
Guía detallada de Android

Instalar en iPhone

  1. Instalá TestFlight. Descargalo desde App Store si todavía no está en el dispositivo.
  2. Abrí la invitación. El botón de esta página llevará únicamente al dominio oficial de TestFlight.
  3. Aceptá y pulsá Instalar. TestFlight mostrará la versión disponible y la información de la prueba.
  4. Actualizá desde TestFlight. Las compilaciones de prueba caducan; la aplicación indicará cuándo hay una nueva.
Guía detallada de iPhone

Instalar en Windows

  1. Descargá el ZIP. Usá únicamente el botón de esta página. Necesitás Windows 10 u 11 de 64 bits.
  2. Verificá el archivo (opcional). Comprobá el nombre y, si está publicado, el SHA-256 antes de abrirlo.
  3. Extraé y ejecutá. Descomprimí el ZIP y abrí giramesa.exe desde la carpeta extraída.
  4. Si aparece SmartScreen. Es habitual en la primera ejecución: pulsá «Más información» y después «Ejecutar de todas formas».

Este portal no usa analítica, cookies ni formularios. El repositorio público no contiene código de la aplicación, credenciales, material de firma ni listas de testers.

  • 02 Windows descarga solo un ZIP publicado en el repositorio configurado.
  • 03 iPhone se deriva únicamente a una invitación válida de TestFlight.
  • 04 Las notas remotas se muestran como texto, nunca como HTML ejecutable.
