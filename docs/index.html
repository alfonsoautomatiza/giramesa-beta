Elegí tu camino

La web te deja empezar en segundos. Las versiones instalables agregan un acceso directo para el dispositivo que usás todos los días.

Usar la web

  1. Abrí Giramesa. Entrá desde cualquier navegador y empezá sin crear una cuenta.
  2. Guardala si querés. Podés agregarla a la pantalla de inicio para volver más rápido.
  3. Tus datos quedan ahí. La información se guarda localmente en ese navegador.
Abrir la versión web

Instalar en Android

  1. Descargá el APK. Usá únicamente el botón de esta página y comprobá el nombre y, si está publicado, el SHA-256.
  2. Abrí la descarga. Android puede pedir permiso puntual para instalar aplicaciones desconocidas.
  3. Instalá y revisá. Si el archivo no coincide o aparece una advertencia inesperada, cancelá y comunicalo.
Guía detallada de Android

Usar en Windows

  1. Descargá el ZIP. Elegí la última publicación disponible en esta página.
  2. Descomprimí la carpeta. Conservá juntos todos los archivos que contiene.
  3. Ejecutá Giramesa. Abrí la aplicación desde la carpeta descomprimida; no es un instalador.
Ver la descarga de Windows

iPhone: pendiente

  1. Usá la web por ahora. Es la alternativa recomendada desde Safari y no requiere instalación.
  2. TestFlight llegará después. El acceso se habilitará solo con una invitación pública válida.
  3. No instales perfiles. No ofrecemos archivos IPA, perfiles de instalación ni registro de UDID.
