# Privacidad

## Resumen

Este sitio estático no usa cookies, analítica, píxeles de seguimiento, formularios ni almacenamiento local. No recopila una lista de testers.

## Solicitudes externas

Al abrir el portal, el navegador consulta la API pública de GitHub para conocer la última Release Android del repositorio configurado. GitHub recibe los datos técnicos habituales de una solicitud web, como la dirección IP y el agente de usuario, bajo sus propias condiciones y política de privacidad.

Al descargar un APK se accede a GitHub. Al abrir una invitación de iPhone se accede a `testflight.apple.com`. El enlace de TestFlight permanece deshabilitado hasta que mantenimiento configure una URL válida.

## Incidencias

Las incidencias de GitHub son públicas. No incluyas:

- Nombre completo, correo, teléfono o ubicación.
- Contraseñas, tokens o códigos de invitación privados.
- Identificadores del dispositivo, UDID o números de serie.
- Capturas con información de otras personas.
- Datos introducidos dentro de la aplicación.

Describí el dispositivo de forma general, la versión del sistema y los pasos para reproducir el problema.
