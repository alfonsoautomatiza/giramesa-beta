# Giramesa Beta

Canal público de las versiones de prueba de **Giramesa**, la app para decidir dónde comer en grupo.

## Probar sin instalar nada

- **Versión navegador:** https://alfonsoautomatiza.github.io/giramesa-beta/app/
- **Portal de pruebas completo** (descargas, estado por plataforma y guías): https://alfonsoautomatiza.github.io/giramesa-beta/

## Descargas

Los instalables se publican como assets de las [GitHub Releases](https://github.com/alfonsoautomatiza/giramesa-beta/releases):

| Plataforma | Asset |
|---|---|
| Android | `giramesa-android-vX.Y.Z-bN.apk` |
| Web (autoalojable) | `giramesa-web-vX.Y.Z-bN.zip` |

Guías de instalación:

- [Instalar en Android](android/INSTALL.md)
- [Instalar en iPhone (TestFlight)](ios/TESTFLIGHT.md)

## Comunicar un problema

[Abrir una incidencia](https://github.com/alfonsoautomatiza/giramesa-beta/issues/new?template=bug-report.yml). El formulario pide no incluir datos personales, credenciales ni información sensible.

## Acerca de este repositorio

- No contiene código fuente de la aplicación ni binarios en el índice git; todo instalable vive en las Releases.
- El portal web se mantiene en la rama [`portal`](https://github.com/alfonsoautomatiza/giramesa-beta/tree/portal) y se publica automáticamente con GitHub Pages.
- [NOTICE.md](NOTICE.md) · [PRIVACY.md](PRIVACY.md) · [SECURITY.md](SECURITY.md)
